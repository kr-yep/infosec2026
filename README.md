| 作業 | 內容 | 進度 |

接下來繳交 HW3，並持續每週更新 HW1，保留新聞來源與實際紀錄日期。

## 繳交方式

依老師的[計分表說明](https://hackmd.io/u32Hk62nR8qMhWIRqqJ2oA)，將 HackMD 或 GitHub 作業網址寄到 `cnchen@pu.edu.tw`，信件主旨須包含 `[學號]` 與作業編號，例如 `[HW3]`。本專區統一採用 `[學號][HW3]`，寄送時換成自己的學號與該次作業編號，內文放該份作業的直接連結。

課程首頁簡寫為 `[HW]學號`；這裡依計分表較完整的說明，保留學號與具體作業編號。老師未指定兩者的排列順序或固定信件內文。

各份作業統一列出題目來源、進度、作業內容或操作步驟、結果與學習觀察。這是本專區的整理方式；HW1 依每則新聞分段，HW2、HW3 依實作步驟與結果分段。

# 2026 資訊安全實務與應用作業

本專區管理「資訊安全實務與應用」課程作業。HW1 的主要內容是持續閱讀資安新聞，整理報導重點並保留來源。

- [課程講義與作業要求](https://hackmd.io/@chiounan/infosec2026)
- [HW1 資安新聞紀錄](security-news.md)
- [GitHub 作業專區](https://github.com/kr-yep/infosec2026)
- [老師的參考範例](https://hackmd.io/@chiounan/security-news)

## HW1 要求

依 2026-10-05 讀取的課程頁：

1. 建立個人 HackMD 或 GitHub 頁面。
2. 記錄資訊安全相關技術或事件的報導，簡單描述內容。
3. 每週至少更新一則，全學期至少 15 則。
4. 將個人頁面網址寄至 `cnchen@pu.edu.tw`；課程頁列出的信件主旨格式為 `[HW]學號`。

課程頁目前明列 HW1；其他講義中的練習尚未逐一盤點。課程成績比例為 Homework/Lab 50%、期中考 30%、期末考 20%。
